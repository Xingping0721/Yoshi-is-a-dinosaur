# Yoshi-is-a-dinosaur
Yoshi is a dinosaur.

## Yoshi's 3D Drive

A small Three.js game in a single file. Open `yoshi.html` in a browser (needs an internet connection to load Three.js).

| Action | Keys |
| --- | --- |
| Move (camera-relative) | `W` `A` `S` `D` / arrow keys |
| Run | `Shift` |
| Shoot (hold) | `Space` |
| Enter / exit car | `F` |
| Respawn car | `R` |
| Rotate / zoom camera | Mouse drag / wheel |
| Hide help | `H` |

Smash every crate — shoot them, or ram them with the car at speed. Crashing into trees too fast damages the car.
